### **Техническое задание на разработку Python-скрипта для автоматизированного формирования PDF-обложек книг**

#### **1. Общая информация**
**Название проекта:** Автоматизированное создание jpg-обложек для книг  
**Описание:** Разработка Python-скрипта, который будет загружать данные из Excel-файла, обрабатывать их, корректно форматировать и создавать PDF-обложки книг с заданным дизайном.  

---

### **2. Функциональные требования**
#### **2.1 Чтение данных из Excel**
1. **Формат входного файла:** `.xlsx`
2. **Путь к файлам:** `data/input/`
3. **Обработка всех `.xlsx` файлов в папке `input`**
4. **Игнорирование заголовков:** данные извлекаются **по порядковым номерам столбцов**:
   - **Столбец A (0):** ISBN (используется только для имени файла, на обложке не печатается)
   - **Столбец B (1):** Авторы
   - **Столбец C (2):** Название книги
   - **Столбец D (3):** Подзаголовок - Том (Volume)
   - **Столбец E (4):** Не используется
   - **Столбец F (5):** Не используется
   - **Столбец G (6):** Не используется
   - **Столбец H (7):** Резервный код (используется как имя файла, если ISBN пуст)
   - **Столбец I (8):** Связующее слово (Ancor)

#### **2.2 Обработка данных и порядок в котором они появляеются на обложке**
1. **ISBN** Столбец A (0) → используется для **названия файла**. Если отсутствует, используется столбец **7** (резервный код).
2. **Название книги** Столбец С (2)    
   - Если длинное, **переносится на несколько строк**
3. **Том (Volume)** Столбец D (3)  
   - Если не указан, ничего не пишется.
4. **Связующее слово (Ancor)** Столбец I (8)
5. **Авторы** Столбец B (1)
   - Формат в Excel: `Фамилия, Имя; Фамилия2, Имя2` Модет быть один автор, два автора или больше. В оригинальном спсике имя и фамилия разделены запятой. Нужно поменять местами (`Имя Фамилия`) убрать запятую и разместить **каждого автора на новой строке в PDF**
6. **Удаление управляющих символов:**  
   - Любые **нечитаемые и специальные символы** удаляются.
   - Unicode **нормализуется** (`NFKC`).
   - Убираются **неразрывные пробелы (`\xa0`)**.

---

### **3. Формирование PDF**
1. **Выходная папка:** `data/output/`
2. **Формат выходного файла:** `.pdf`
3. **Имя файла:**  
   - `ISBN.pdf`, если ISBN есть  
   - `РезервныйКод.pdf`, если ISBN отсутствует  
   - `формируется из названия книги.pdf`, если оба поля пустые
4. **Структура контента (в центре PDF)**
   - **Название книги** (перенос длинных строк)
   - **Авторы** (каждый на отдельной строке)
   - **Том** (Volume)
   5. **Форматирование текста**
   - Шрифт: **Brush Script MT** (если доступен)  
     - Если **нет**, то `"Helvetica-Oblique"`
   - Цвет фона: **#0057B7** (Синий)
   - Цвет текста: **Белый**
   - Размеры шрифтов:
     - Заголовок: **24**
     - Автор: **18**
     - Том:
6. **Логотип (если есть)**
   - Путь к файлу логотипа **задаётся в конфигурационной части вверху скрипта**.
   - Размещается **внизу страницы по центру**.
7. **Выравнивание текста**
   - Весь текст **центрируется на странице**.
   - Если строка не помещается, **автоматический перенос**.
7. **Размер обложки**
   - 15,24 см × 22,86 см
---

### **4. Ошибки и логирование**
1. **Логирование каждого обработанного файла:**
   ```plaintext
   Обрабатываю строку: ISBN=123456789, Авторы=['Имя1 Фамилия1', 'Имя2 Фамилия2'], Название=Название книги, Том=1
   Сохраняю PDF в: data/output/123456789.jpg
   ```
2. **Обработка ошибок**
   - Если ошибка при чтении Excel → выводить сообщение и **пропускать файл**.
   - Если PDF не создан, вывести причину.
